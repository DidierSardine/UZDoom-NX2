UZDoom NX2 - Installation and Usage
===================================

Requirements
------------

- A Nintendo Switch 2 setup that supports kaiHEN homebrew and hbmenu.
- An SD card with enough free space for the package, IWADs, and mods.
- A UZDoom NX2 release package.

Install to the SD card
----------------------

1. Extract the release ZIP.
2. Copy its `switch` folder to the root of the SD card. The program should be at:
   sdmc:/switch/uzdoom-nx2/uzdoom-nx2.nro
3. The package includes Freedoom Phase 1 and Phase 2 in:
   sdmc:/switch/uzdoom-nx2/iwads/
4. Safely eject the SD card and insert it into the console.

Launch
------

1. Start kaiHEN.
2. Open hbmenu by holding R while launching a game.
3. Select UZDoom NX2.
4. In the launcher, select a profile with L/R, review its IWAD and mod load order, then press + to launch.

Use your own legally obtained IWADs by copying them into:
sdmc:/switch/uzdoom-nx2/iwads/

Place mods and map packs in:
sdmc:/switch/uzdoom-nx2/mods/

Supported mod file types include .pk3, .wad, .zip, .pk7, .deh, .bex, and .ipk3. Subfolders are allowed. Files in these folders are user-managed and are not removed when a profile changes.

Launcher controls
-----------------

- A: select
- B: go back
- L/R: switch profile
- +: launch
- -: edit the selected profile
- In the mod list: A toggles a mod, Y changes its position, X removes it from the profile, and + adds a mod

In-game settings
----------------

- Change the launcher language in Settings > Language.
- Gyro aiming and rumble are off by default. Configure them under Options > Controller Options.
- The left-stick click levels the view and resets gyro aiming by default. Rebind it under Customize Controls > Actions.
- In the console, A types or runs a command, X erases, and B closes the keyboard.

Files and troubleshooting
------------------------

The application stores configuration, saves, screenshots, caches, and logs under:
sdmc:/switch/uzdoom-nx2/

Logs are stored in the logs/ subfolder. If reporting a problem, include relevant files such as crash.log, error.log, engine-session.txt, rdoom.log, engine.log, and perf.log. Review logs before sharing them and remove any personal information.

Known compatibility issue
-------------------------

Some mods are not functional yet, such as myhouse.wad. Mods such as Brutal Doom and Reelism have been tested and work.

Clock settings
--------------

UZDoom NX2 does not overclock the console. It uses the console's stock clock settings.
