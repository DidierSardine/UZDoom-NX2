UZDoom NX2 - installation (Nintendo Switch 2, kaiHEN)
====================================================

UZDoom NX2 is an unofficial port of UZDoom 5.0.3 to the Nintendo Switch 2
under kaiHEN, rendered with Vulkan (OunceVK), with its own launcher.

1. Copy the "switch" folder of this package to the ROOT of the SD card.
   Result: sdmc:/switch/uzdoom-nx2/uzdoom-nx2.nro with the .pk3 files next to
   it, and the free Freedoom IWADs in sdmc:/switch/uzdoom-nx2/iwads/.

2. Optional: add your own IWADs to  sdmc:/switch/uzdoom-nx2/iwads/
   (doom.wad, doom2.wad, plutonia.wad, tnt.wad, heretic.wad, hexen.wad ...
   from games you own).

3. Optional: put mods and map packs in  sdmc:/switch/uzdoom-nx2/mods/
   (.pk3 .wad .zip .pk7 .deh .bex .ipk3; subfolders allowed)

4. Start kaiHEN, then start a game while holding R to open hbmenu, and choose
   UZDoom NX2. (The homebrew then runs in the game's process, with all its
   memory.)

5. In the launcher: choose a profile (L/R), check the IWAD and mods, press +.
   The language (English, French, Portuguese) is in Settings > Language.

In game
  Gyro aiming and rumble are off by default: Options > Controller Options.
  Left stick click: level the view and reset the gyro (rebind it in
  Customize Controls > Actions).
  Console: A types and runs a command (Switch keyboard), X erases, B closes.

Launcher controls
  A select   B back   L/R change profile   + launch   - edit profile
  Mod list: A enable/disable, Y move (D-Pad), X remove, + add

Safe for your console
  UZDoom NX2 only writes inside sdmc:/switch/uzdoom-nx2 and never touches
  the console's system memory (NAND). A guard refuses every write anywhere
  else; if it cannot start, the program does not start either.

Folders (everything is in switch/uzdoom-nx2/)
  iwads/ mods/            your files (never deleted)
  profiles/               profiles (.json)
  config/engine/          engine settings per profile
  saves/<profile>/        saves per profile
  screenshots/            in-game screenshots
  cache/                  thumbnails, Vulkan pipeline cache
  logs/                   rdoom.log, engine.log, perf.log, crash.log, error.log
  launcher/               launcher images
  backup/ export/         safety copies and exported profiles
  licenses/               licences and credits

Clocks
  Stock console clocks only. No overclocking.

If something goes wrong
  Send the contents of switch/uzdoom-nx2/logs/ (crash.log, error.log,
  engine-session.txt, rdoom.log, engine.log, engine-stderr.log) and
  switch/uzdoom-nx2/hang.log if there is one.
